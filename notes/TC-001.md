# TC-001 — The correction arrived tomorrow

**Tracked revision:** `2026-09-25.1` (25 September 2026)  
**Problem:** decision-time knowledge  
**Canonical page:** <https://tntresearch.co.uk/temporal-club/notes/001-the-correction-arrived-tomorrow.html>  
**Case data:** [tc-001.json](../cases/tc-001.json)

A fictional feed publishes `101.20` for instrument X at 09:01 BST on 14 April 2026. An agent records a buy decision at 09:10. The next morning, the feed corrects that earlier snapshot to `100.80`.

The current corrected source value is `100.80`; the value published before the decision was `101.20`. The case does **not** establish that `101.20` reached this agent before 09:10. The agent had feed entitlement, but delivery latency is unknown. It also does not establish what the agent actually observed or used: there is no agent input record.

The challenge is to add the smallest fact that changes the answer about availability or observation. A delivery receipt, cached-feed snapshot, or decision input record would answer a different part of the question. A later correction cannot be silently substituted into the agent's earlier decision context.

The values and instrument are synthetic. All event instants are recorded in `Europe/London` with explicit `+01:00` offsets in the [case data](../cases/tc-001.json).
